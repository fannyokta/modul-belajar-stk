Bab 8

Vektor dan Geometri Analitik

Di T-Kurs, geometri ruang hampir selalu diselesaikan dengan vektor: garis, bidang, jarak, dan sudut. Kuncinya adalah tiga alat (hasil kali titik, hasil kali silang, dan vektor normal) serta kebiasaan menulis persamaan dengan rapi.

Konvensi penulisan: titik ditulis P(1|2|3) seperti di Jerman. Vektor kolom ditulis datar dalam teks sebagai (1; 2; 3), tetapi tetap bermakna vektor kolom.

8.1 Dasar vektor di ruang

  • Verbindungsvektor dari A ke B: AB = B − A (koordinat B dikurangi koordinat A).
  • Betrag (panjang): |a| = √(a₁² + a₂² + a₃²).
  • Titik tengah (Mittelpunkt) AB: M = (A + B)/2.
  • Einheitsvektor (vektor satuan) searah a: a/|a|.
  • Lineare Abhängigkeit: a dan b kolinear jika a = k · b untuk suatu bilangan k.

Contoh 1. A(1|2|3) dan B(4|6|15). Maka AB = (3; 4; 12), |AB| = √(9 + 16 + 144) = √169 = 13, dan M(2,5|4|9).

8.2 Hasil kali titik (Skalarprodukt)

\vec a \cdot \vec b = a_1 b_1 + a_2 b_2 + a_3 b_3 = |\vec a|\,|\vec b|\cos\varphi

Dua vektor orthogonal (tegak lurus) jika dan hanya jika hasil kali titiknya 0. Sudut antarvektor:

\cos\varphi = \frac{\vec a \cdot \vec b}{|\vec a|\,|\vec b|}

Contoh 2. a = (1; 2; 2) dan b = (2; −1; 2). a · b = 2 − 2 + 4 = 4, |a| = 3, |b| = 3. Maka cos φ = 4/9 dan φ ≈ 63,6°.

8.3 Hasil kali silang (Kreuzprodukt) dan Spatprodukt

\vec a \times \vec b = \begin{pmatrix} a_2 b_3 - a_3 b_2 \\ a_3 b_1 - a_1 b_3 \\ a_1 b_2 - a_2 b_1 \end{pmatrix}

a × b tegak lurus terhadap a dan b sekaligus, dan |a × b| adalah luas jajargenjang yang dibentuk a dan b. Luas segitiga = ½ |a × b|. Volume bangun yang dibentuk tiga vektor a, b, c (Spat, balok miring) adalah |(a × b) · c|, dan volume limas segitiga (tetrahedron) adalah 1/6 dari itu.

Contoh 3. a = (1; 2; 3) dan b = (0; 1; −1). Maka a × b = (2·(−1) − 3·1; 3·0 − 1·(−1); 1·1 − 2·0) = (−5; 1; 1). Cek ortogonal: a · (−5; 1; 1) = −5 + 2 + 3 = 0 ✓. Panjangnya √27 = 3√3.

Contoh 4. Luas segitiga A(1|0|0), B(0|2|0), C(0|0|3): AB = (−1; 2; 0) dan AC = (−1; 0; 3). AB × AC = (6; 3; 2), panjangnya √(36 + 9 + 4) = 7. Luas = 3,5.

8.4 Garis (Gerade)

g:\; \vec x = \vec p + t\,\vec u, \qquad t \in \mathbb{R}

dengan p vektor posisi satu titik pada garis (Stützvektor) dan u vektor arah (Richtungsvektor). Garis melalui dua titik A dan B: p = A dan u = B − A.

Posisi dua garis g dan h:

  • Vektor arah kelipatan satu sama lain: sejajar (parallel), atau berimpit (identisch) jika satu titik g juga ada di h.
  • Tidak sejajar dan sistem persamaannya punya satu solusi: berpotongan (schneiden sich), dengan titik potong dari solusi itu.
  • Tidak sejajar dan sistem persamaannya tak punya solusi: bersilangan (windschief).

Sudut antargaris memakai |u · v|/(|u||v|), supaya sudutnya tidak lebih dari 90°.

Contoh 5 (titik potong dan sudut). g: x = (1; 2; 0) + t(1; 1; 2) dan h: x = (1; 3; 1) + s(1; 0; 1).

Samakan tiap koordinat. Dari x: 1 + t = 1 + s, jadi t = s. Dari y: 2 + t = 3, jadi t = 1 dan s = 1. Cek z: 2t = 2 dan 1 + s = 2 ✓. Titik potong: S(2|3|2). Sudut: u · v = 1 + 0 + 2 = 3, |u| = √6, |v| = √2, jadi cos φ = 3/√12 = √3/2 dan φ = 30°.

Contoh 6 (jarak titik ke garis). P(3|1|2) dan garis g: x = t(1; 2; 2). Jarak = |(P − Q) × u| / |u| dengan Q titik pada garis. Dengan Q = titik asal: (3; 1; 2) × (1; 2; 2) = (−2; −4; 5), panjangnya √45 = 3√5, dan |u| = 3. Jadi jaraknya √5 ≈ 2,24.

Jarak dua garis bersilangan dihitung dengan vektor normal n = u × v: d = |(Pₕ − P_g) · n| / |n|. Contoh: g melalui titik asal dengan arah (1; 0; 0), dan h melalui (0; 1; 0) dengan arah (0; 0; 1). n = (0; −1; 0), dan d = |(0; 1; 0) · (0; −1; 0)|/1 = 1.

8.5 Bidang (Ebene)

Tiga bentuk persamaan, dan kamu harus bisa mengubah satu ke yang lain:

\text{Parameterform: } \vec x = \vec p + r\,\vec u + s\,\vec v
\text{Normalenform: } \vec n \cdot (\vec x - \vec p) = 0, \qquad \text{Koordinatenform: } n_1 x + n_2 y + n_3 z = d

Contoh 7 (dari parameter ke koordinat). E: x = (1; 0; 2) + r(1; 1; 0) + s(0; 1; 1). Vektor normal n = (1; 1; 0) × (0; 1; 1) = (1; −1; 1). Maka x − y + z = d, dan titik (1|0|2) memberi d = 3. Jadi E: x − y + z = 3.

Contoh 8 (bidang melalui tiga titik). A(1|0|0), B(0|2|0), C(0|0|3). Dari Contoh 4, n = AB × AC = (6; 3; 2). Maka 6x + 3y + 2z = d dan A memberi d = 6, sehingga E: 6x + 3y + 2z = 6.

Jarak titik ke bidang (rumus Hessesche Normalenform):

d(Q, E) = \frac{|n_1 q_1 + n_2 q_2 + n_3 q_3 - d|}{|\vec n|}

Untuk Q(1|1|1) dan bidang pada Contoh 8: d = |6 + 3 + 2 − 6|/√49 = 5/7 ≈ 0,71.

Garis dan bidang. Substitusikan x, y, z dari persamaan garis ke persamaan bidang. Satu solusi t memberi titik tembus. Tidak ada solusi (0 = bilangan tak nol) berarti sejajar. Semua t berlaku berarti garis terletak di bidang. Sudut garis-bidang φ memenuhi sin φ = |n · u|/(|n||u|).

Contoh: garis x = t(1; 1; 1) dan bidang pada Contoh 8. Substitusi: 6t + 3t + 2t = 6, jadi t = 6/11. Titik tembus (6/11 | 6/11 | 6/11). Sudutnya: sin φ = 11/(7√3) ≈ 0,907, jadi φ ≈ 65,1°.

Latihan 8

  • 8.1 A(2|−1|3) dan B(5|3|15). Tentukan vektor AB, panjang |AB|, dan titik tengahnya.
  • 8.2 (a) Hitung sudut antara a = (1; 1; 0) dan b = (0; 1; 1). (b) Tentukan t agar (2; t; 1) tegak lurus terhadap (3; −4; −2).
  • 8.3 Hitung a × b untuk a = (2; 0; 1) dan b = (1; 3; −1). Cek ortogonalitasnya, lalu hitung luas jajargenjang.
  • 8.4 Hitung luas segitiga A(1|1|1), B(3|1|2), C(2|4|1).
  • 8.5 Hitung volume Spat yang dibentuk (1; 0; 0), (1; 2; 0), (1; 1; 3), dan volume tetrahedron yang sesuai.
  • 8.6 Periksa posisi g: x = (1; 2; 0) + t(1; 1; 2) terhadap h: x = (2; 0; 1) + s(2; 2; 4).
  • 8.7 g: x = (0; 1; 2) + t(2; 1; 0) dan h: x = (3; 4; 1) + s(1; −1; 1). Tentukan titik potong dan sudutnya.
  • 8.8 Hitung jarak P(2|0|0) ke garis x = t(0; 3; 4).
  • 8.9 Hitung jarak antara garis g: x = t(1; 1; 0) dan h: x = (0; 0; 2) + s(1; −1; 0), yang bersilangan.
  • 8.10 Tentukan persamaan koordinat bidang melalui A(2|0|0), B(0|3|0), C(0|0|6), lalu hitung jarak P(2|2|2) ke bidang itu.
  • 8.11 Ubah ke bentuk koordinat: E: x = (0; 1; 0) + r(1; 0; 2) + s(0; 1; 1).
  • 8.12 Tentukan titik tembus dan sudut antara garis x = t(1; 1; 1) dan bidang 2x + y − z = 1.
