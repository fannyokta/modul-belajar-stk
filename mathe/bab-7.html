Barisan dan Deret

Folge adalah daftar bilangan berurutan a₁, a₂, a₃, …, dan Reihe adalah jumlahnya. Materi ini mungkin sudah kamu kenal sebelumnya, tetapi di Jerman sering dibutuhkan lagi untuk bunga majemuk, deret tak hingga, dan pembuktian.

7.1 Barisan dan deret aritmetika (arithmetische Folge)

Selisih antarsuku tetap, yaitu d.

a_n = a_1 + (n-1)\,d, \qquad S_n = \frac{n}{2}\,(a_1 + a_n) = \frac{n}{2}\,\big(2a_1 + (n-1)d\big)

Contoh 1. a₁ = 5 dan d = 3. Maka a₂₀ = 5 + 19·3 = 62 dan S₂₀ = 10 · (5 + 62) = 670.

7.2 Barisan dan deret geometri (geometrische Folge)

Rasio antarsuku tetap, yaitu q.

a_n = a_1\, q^{\,n-1}, \qquad S_n = a_1 \cdot \frac{1 - q^n}{1 - q} \quad (q \neq 1)

Deret geometri tak hingga konvergen hanya jika |q| < 1, dan jumlahnya:

S_\infty = \frac{a_1}{1 - q}

Contoh 2. a₁ = 3 dan q = 2. Maka a₈ = 3 · 2⁷ = 384 dan S₈ = 3 · (2⁸ − 1)/(2 − 1) = 765.

Contoh 3 (tak hingga). 1 + 1/2 + 1/4 + … mempunyai a₁ = 1 dan q = 1/2, jadi S = 1/(1 − 1/2) = 2.

Contoh 4 (desimal berulang). 0,333… = 0,3 + 0,03 + 0,003 + … dengan a₁ = 0,3 dan q = 0,1, jadi S = 0,3/0,9 = 1/3.

Contoh 5 (bola memantul). Bola dijatuhkan dari 10 m dan tiap pantulan mencapai 60% tinggi sebelumnya. Tinggi pantulan: 6; 3,6; … berjumlah 6/(1 − 0,6) = 15 m. Tiap pantulan menempuh naik dan turun, jadi jarak total = 10 + 2 · 15 = 40 m.

7.3 Notasi sigma dan jumlah penting

\sum_{k=1}^{n} k = \frac{n(n+1)}{2}, \qquad \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}, \qquad \sum_{k=1}^{n} c = n\,c

Notasi sigma bersifat linear: Σ(a·uₖ + b·vₖ) = a·Σuₖ + b·Σvₖ.

Contoh 6. Σ dari k = 1 sampai 10 dari (2k + 1) = 2 · 55 + 10 = 120.

7.4 Konvergensi barisan dan bunga majemuk

Barisan konvergen ke L jika aₙ mendekati L untuk n → ∞ (teknik sama dengan Bab 4).

Contoh 7. aₙ = (3n + 1)/(n + 2). Bagi dengan n: (3 + 1/n)/(1 + 2/n) → 3.

Bunga majemuk (Zinseszins): modal K₀ dengan bunga p per periode menjadi Kₙ = K₀ · (1 + p)ⁿ.

Contoh 8. €5.000 dengan bunga 3% per tahun selama 8 tahun menjadi 5.000 · 1,03⁸ ≈ €6.333,85.

7.5 Pembuktian dengan induksi (vollständige Induktion)

Berguna untuk membuktikan rumus yang berlaku untuk semua n ∈ ℕ. Tiga langkah: Induktionsanfang (cek n = 1), Induktionsannahme (anggap benar untuk n), Induktionsschritt (buktikan benar untuk n + 1).

Contoh 9. Buktikan 1 + 2 + … + n = n(n+1)/2.

Anfang: untuk n = 1, kiri = 1 dan kanan = 1·2/2 = 1. Annahme: anggap berlaku untuk n. Schritt: untuk n + 1, jumlah = n(n+1)/2 + (n+1) = (n+1)(n/2 + 1) = (n+1)(n+2)/2. Itu persis rumus untuk n + 1. Terbukti.
