Ini bab terpenting di T-Kurs. Hampir setiap ujian memuat satu soal Kurvendiskussion (analisis lengkap grafik) dan satu soal Extremwertaufgabe (optimasi). Targetnya: bisa menurunkan fungsi apa pun dengan lancar, lalu memakai turunan untuk menganalisis grafik.

5.1 Definisi turunan (Ableitung)

Turunan adalah kemiringan garis singgung (Tangente), atau laju perubahan sesaat:

f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}

Bentuk di dalam limit disebut Differenzenquotient (kemiringan garis potong, laju perubahan rata-rata), dan limitnya disebut Differentialquotient.

Contoh 1. f(x) = x².

((x + h)² − x²)/h = (2xh + h²)/h = 2x + h, dan untuk h → 0 hasilnya f′(x) = 2x.

Garis singgung dan garis normal di titik x₀:

\text{Tangente: } y = f'(x_0)\,(x - x_0) + f(x_0), \qquad \text{Normale: } y = -\frac{1}{f'(x_0)}\,(x - x_0) + f(x_0)

Contoh 2 (Produktregel). f(x) = x² e^(3x).

u = x² dan v = e^(3x), sehingga u′ = 2x dan v′ = 3e^(3x) (Kettenregel). Maka f′(x) = 2x e^(3x) + x² · 3e^(3x) = x e^(3x)(2 + 3x).

Contoh 3 (Quotientenregel). f(x) = (x² + 1)/(x − 1).

f′(x) = [2x(x − 1) − (x² + 1)·1]/(x − 1)² = (x² − 2x − 1)/(x − 1)².

Contoh 4 (Kettenregel).

  • (sin(x²))′ = cos(x²) · 2x
  • (ln(x² + 1))′ = 2x/(x² + 1)
  • ((3x − 2)⁵)′ = 5(3x − 2)⁴ · 3 = 15(3x − 2)⁴
  • (√(1 + x²))′ = x/√(1 + x²)

Contoh 5 (garis singgung). f(x) = x³ − 2x di x = 1.

f(1) = −1 dan f′(x) = 3x² − 2, jadi f′(1) = 1. Tangente: y = 1·(x − 1) − 1 = x − 2. Normale (kemiringan −1): y = −(x − 1) − 1 = −x.

5.3 Kurvendiskussion: urutan kerja

  1. Definitionsmenge dan Symmetrie. Periksa f(−x).
  2. Nullstellen dan titik potong sumbu y f(0).
  3. Verhalten im Unendlichen (dan asimtot, jika fungsinya rasional atau eksponen).
  4. Extrempunkte: hitung f′ dan f″. Syarat perlu (notwendige Bedingung): f′(x₀) = 0. Syarat cukup (hinreichende Bedingung): f″(x₀) < 0 memberi Hochpunkt (maksimum lokal), dan f″(x₀) > 0 memberi Tiefpunkt (minimum lokal).
  5. Wendepunkte: f″(x₀) = 0 dan f‴(x₀) ≠ 0. Titik belok adalah tempat grafik berganti arah lengkung.
  6. Monotonie dan Krümmung: f′ > 0 berarti grafik naik, dan f″ > 0 berarti grafik cekung ke atas (linkskurve), f″ < 0 berarti cekung ke bawah (rechtskurve).
  7. Wertetabelle beberapa titik, lalu sketsa.

Satu catatan penting: jika f′(x₀) = 0 dan f″(x₀) = 0, kriteria f″ tidak cukup, dan kamu perlu memeriksa perubahan tanda f′ (Vorzeichenwechsel).

Contoh 6 (lengkap). f(x) = x³ − 6x² + 9x.

  • Turunan: f′(x) = 3x² − 12x + 9 = 3(x − 1)(x − 3), f″(x) = 6x − 12, f‴(x) = 6.
  • Simetri: tidak ada (campuran pangkat ganjil dan genap).
  • Nol: f(x) = x(x − 3)², jadi x = 0 (nol tunggal) dan x = 3 (nol ganda). Titik potong sumbu y: 0.
  • Perilaku tak hingga: derajat 3 dengan koefisien positif, jadi x → +∞ memberi +∞ dan x → −∞ memberi −∞.
  • Ekstrem: f′ = 0 di x = 1 dan x = 3. f″(1) = −6 < 0, jadi H(1|4) karena f(1) = 1 − 6 + 9 = 4. f″(3) = 6 > 0, jadi T(3|0) (konsisten dengan nol ganda di x = 3).
  • Titik belok: f″ = 0 di x = 2, dan f‴ = 6 ≠ 0. f(2) = 8 − 24 + 18 = 2, jadi W(2|2). Kemiringan garis singgung di titik belok f′(2) = −3.
  • Monotonie: naik pada (−∞; 1) dan (3; ∞), turun pada (1; 3). Krümmung: cekung ke bawah untuk x < 2, cekung ke atas untuk x > 2.

5.4 Soal optimasi (Extremwertaufgaben)

Urutan kerja:

  1. Tentukan besaran yang dioptimalkan dan tulis sebagai Zielfunktion.
  2. Tulis syarat yang diketahui sebagai Nebenbedingung, lalu pakai untuk menyisakan satu peubah.
  3. Tentukan daerah definisi yang masuk akal (panjang tidak boleh negatif).
  4. Turunkan, selesaikan f′ = 0, dan uji dengan f″ (atau periksa ujung daerah).
  5. Hitung nilai optimumnya dan tulis Antwortsatz.

Contoh 7. Dari karton persegi 12 cm × 12 cm dibuat kotak tanpa tutup dengan memotong persegi sisi x di keempat sudutnya. Tentukan x agar volume maksimum.

Volume V(x) = x(12 − 2x)² dengan 0 < x < 6. Jabarkan: V(x) = 4x³ − 48x² + 144x. Maka V′(x) = 12x² − 96x + 144 = 12(x − 2)(x − 6), jadi x = 2 (x = 6 di luar daerah). V″(x) = 24x − 96, dan V″(2) = −48 < 0, jadi itu maksimum. V(2) = 2 · 8² = 128. Antwortsatz: dengan x = 2 cm volume kotak maksimum, yaitu 128 cm³.

5.5 Dua alat bantu tambahan

Aturan L’Hôpital (untuk bentuk 0/0 atau ∞/∞):

\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}

Contoh: lim (eˣ − 1)/x untuk x → 0 sama dengan lim eˣ/1 = 1.

Newton-Verfahren (pendekatan nol fungsi secara berulang):

x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}

Contoh: f(x) = x² − 2 dengan x₀ = 1,5. Maka f(1,5) = 0,25 dan f′(1,5) = 3, sehingga x₁ = 1,5 − 0,25/3 ≈ 1,4167 (nilai sebenarnya √2 ≈ 1,4142).
