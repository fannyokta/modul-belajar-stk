10.1 Bentuk aljabar

Satuan imajiner i didefinisikan oleh i² = −1. Bilangan kompleks z = a + bi dengan Realteil a = Re(z) dan Imaginärteil b = Im(z). Sekawan (konjugiert komplexe Zahl) z̄ = a − bi, dan panjang (Betrag) |z| = √(a² + b²). Berlaku z · z̄ = |z|².

  • Penjumlahan dan perkalian: seperti aljabar biasa, tetapi i² diganti −1.
  • Pembagian: kalikan pembilang dan penyebut dengan sekawan penyebut.

Contoh 1. (3 + 2i)(1 − i) = 3 − 3i + 2i − 2i² = 3 − i + 2 = 5 − i.

Contoh 2. (3 + 2i)/(1 − i). Kalikan dengan (1 + i)/(1 + i): pembilang 3 + 3i + 2i + 2i² = 1 + 5i, penyebut 1 + 1 = 2. Hasilnya (1 + 5i)/2 = 0,5 + 2,5i.

Contoh 3 (persamaan kuadrat). x² + 2x + 5 = 0 dengan D < 0. Maka x = −1 ± √(1 − 5) = −1 ± 2i.

10.2 Bidang Gauss dan bentuk polar

z = a + bi digambar sebagai titik (a; b) di Gaußsche Zahlenebene. Dengan jarak r = |z| dan sudut φ (argumen, diukur dari sumbu real positif):

z = r(\cos\varphi + i\sin\varphi) = r\,e^{i\varphi}

Dua bentuk terakhir dihubungkan rumus Euler e^(iφ) = cos φ + i sin φ. Keuntungan bentuk polar: perkalian menjadi mudah.

z_1 z_2 = r_1 r_2\, e^{i(\varphi_1 + \varphi_2)}, \qquad z^n = r^n\,(\cos n\varphi + i\sin n\varphi) \quad \text{(Moivre)}

Saat mencari φ, perhatikan kuadran titik. Jangan langsung memakai arctan(b/a) tanpa memeriksa tanda a dan b.

Contoh 4. z = 1 + i. Maka r = √2 dan φ = π/4 (kuadran I).

Contoh 5. z = −1 + √3 i. Maka r = 2, cos φ = −1/2, dan sin φ = √3/2, jadi φ = 2π/3 (kuadran II).

Contoh 6 (pangkat). (1 + i)⁸ = (√2)⁸ · (cos 8·π/4 + i sin 8·π/4) = 16 (cos 2π + i sin 2π) = 16.

Akar ke-n. Persamaan zⁿ = w dengan w = r_w · e^(iφ_w) punya tepat n solusi:

z_k = \sqrt[n]{r_w}\; e^{\,i\,(\varphi_w + 2\pi k)/n}, \qquad k = 0, 1, \dots, n-1

Contoh 7. z³ = 8. Di sini r_w = 8 dan φ_w = 0, jadi zₖ = 2 e^(i·2πk/3). Untuk k = 0, 1, 2: z = 2, z = −1 + √3 i, dan z = −1 − √3 i. Ketiganya membentuk segitiga sama sisi pada lingkaran jari-jari 2.

10.3 Penerapan: impedansi (arus bolak-balik)

Di teknik elektro satuan imajiner sering ditulis j (karena i dipakai untuk arus). Impedansi seri hambatan R dan induktor adalah Z = R + jωL. Besarnya |Z| = √(R² + (ωL)²) dan beda fase φ = arctan(ωL/R).

Contoh 8. R = 30 Ω dan ωL = 40 Ω. Maka |Z| = √(900 + 1600) = 50 Ω dan φ = arctan(4/3) ≈ 53,1°.
