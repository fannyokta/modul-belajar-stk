Integral adalah kebalikan turunan sekaligus alat untuk menghitung luas, volume, dan besaran yang terakumulasi. Di T-Kurs soalnya biasanya berupa luas daerah, volume benda putar, dan teknik substitusi atau integrasi parsial.

6.1 Stammfunktion dan integral tak tentu

Fungsi F disebut Stammfunktion (antiturunan) dari f jika F′(x) = f(x). Himpunan semua antiturunan ditulis dengan konstanta C:

\int f(x)\,dx = F(x) + C

Antiturunan yang perlu hafal:

  • ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C untuk n ≠ −1
  • ∫ 1/x dx = ln|x| + C
  • ∫ eˣ dx = eˣ + C, dan ∫ e^(ax) dx = e^(ax)/a + C
  • ∫ sin x dx = −cos x + C, dan ∫ cos x dx = sin x + C
  • ∫ sin(ax + b) dx = −cos(ax + b)/a + C, dan ∫ cos(ax + b) dx = sin(ax + b)/a + C
  • ∫ (ax + b)ⁿ dx = (ax + b)ⁿ⁺¹/(a(n+1)) + C
  • ∫ 1/(ax + b) dx = ln|ax + b|/a + C

Cara memeriksa: turunkan hasilnya, harus kembali ke fungsi semula.

6.2 Integral tentu dan Hauptsatz

\int_a^b f(x)\,dx = F(b) - F(a) = \Big[F(x)\Big]_a^b

Ini disebut Hauptsatz der Differential- und Integralrechnung. Nilai integral tentu adalah luas bertanda (orientierter Flächeninhalt): bagian di bawah sumbu x dihitung negatif. Sifat penting: ∫ₐᵇ f = −∫ᵇₐ f, dan ∫ₐᶜ f = ∫ₐᵇ f + ∫ᵇᶜ f.

Contoh 1. ∫₀² (3x² − 2x + 1) dx = [x³ − x² + x] dari 0 sampai 2 = (8 − 4 + 2) − 0 = 6.

Contoh 2. ∫₀^π sin x dx = [−cos x] dari 0 sampai π = (−cos π) − (−cos 0) = 1 + 1 = 2.

Nilai rata-rata (Mittelwert) fungsi pada [a; b] adalah (1/(b − a)) · ∫ₐᵇ f(x) dx.

6.3 Luas daerah (Flächenberechnung)

Aturan inti: luas selalu positif, jadi jika grafik memotong sumbu x di dalam interval, pecah integralnya di setiap nol lalu ambil nilai mutlak tiap bagian.

  • Antara grafik dan sumbu x: cari nol dulu, integralkan per bagian, jumlahkan nilai mutlaknya.
  • Antara dua grafik f dan g: cari titik potong (f = g) sebagai batas, lalu integralkan (atas − bawah).

Contoh 3. Luas antara f(x) = x² − 4 dan sumbu x.

Nol: x = ±2. Pada (−2; 2) grafik berada di bawah sumbu x. ∫₋₂² (x² − 4) dx = [x³/3 − 4x] dari −2 sampai 2 = (8/3 − 8) − (−8/3 + 8) = −32/3. Luasnya adalah nilai mutlaknya: 32/3.

Contoh 4. Luas antara f(x) = x² dan g(x) = 2x + 3.

Titik potong: x² = 2x + 3, jadi x² − 2x − 3 = 0 dan x = −1 atau x = 3. Di antara keduanya g berada di atas f. A = ∫₋₁³ (2x + 3 − x²) dx = [x² + 3x − x³/3] dari −1 sampai 3 = 9 − (−5/3) = 32/3.

Contoh 5 (hati-hati tanda). ∫₀^(2π) sin x dx = 0, tetapi luas antara grafik sin x dan sumbu x pada [0; 2π] adalah 2 + 2 = 4, karena bagian di bawah sumbu x harus dihitung terpisah.

6.4 Teknik integrasi

Substitution (kebalikan Kettenregel). Untuk ∫ f(g(x)) · g′(x) dx, misalkan u = g(x) sehingga du = g′(x) dx:

\int f(g(x))\,g'(x)\,dx = \int f(u)\,du

Pada integral tentu, ubah juga batasnya ke peubah u, atau kembalikan ke x sebelum memasukkan batas.

Contoh 6. ∫ 2x e^(x²) dx. Misal u = x², du = 2x dx. Maka ∫ e^u du = e^u + C = e^(x²) + C.

Contoh 7. ∫₀¹ x√(1 + x²) dx. Misal u = 1 + x², du = 2x dx, jadi x dx = du/2. Batas: x = 0 memberi u = 1, dan x = 1 memberi u = 2. Maka ½ ∫₁² √u du = ½ · (2/3) u^(3/2) dari 1 sampai 2 = (2√2 − 1)/3 ≈ 0,61.

Partielle Integration (kebalikan Produktregel):

\int u\,v'\,dx = u\,v - \int u'\,v\,dx

Pilih u sebagai bagian yang jadi lebih sederhana setelah diturunkan (biasanya polinom atau ln x), dan v′ sebagai bagian yang mudah diintegralkan (eˣ, sin x, cos x).

Contoh 8. ∫ x eˣ dx. Pilih u = x dan v′ = eˣ, jadi u′ = 1 dan v = eˣ. Maka x eˣ − ∫ eˣ dx = (x − 1)eˣ + C.

Contoh 9. ∫₁^e ln x dx. Pilih u = ln x dan v′ = 1, jadi u′ = 1/x dan v = x. Maka [x ln x − x] dari 1 sampai e = (e − e) − (0 − 1) = 1.

6.5 Volume benda putar (Rotationskörper)

Jika grafik f pada [a; b] diputar mengelilingi sumbu x:

V = \pi \int_a^b \big(f(x)\big)^2\,dx

Contoh 10. f(x) = √x pada [0; 4].

V = π ∫₀⁴ x dx = π · [x²/2] dari 0 sampai 4 = 8π ≈ 25,1.

6.6 Integral tak wajar (Uneigentliche Integrale)

Batas atas tak hingga dihitung sebagai limit:

\int_1^\infty \frac{1}{x^2}\,dx = \lim_{b \to \infty} \Big[-\frac{1}{x}\Big]_1^b = \lim_{b \to \infty}\left(1 - \frac{1}{b}\right) = 1

Sebaliknya ∫₁^∞ 1/x dx divergen, karena ln b → ∞. Gagasan “luas tak hingga bisa bernilai berhingga” ini sering muncul sebagai soal.

  • 6.2 Hitung ∫₁³ (2x + 1) dx.
  • 6.3 Hitung ∫₀^(π/2) cos x dx.
  • 6.4 Hitung luas daerah antara f(x) = x² − 2x − 3 dan sumbu x.
  • 6.5 Hitung luas daerah yang dibatasi f(x) = x³ dan g(x) = x.
  • 6.6 Hitung ∫₀^(2π) sin x dx dan luas antara grafik sin x dan sumbu x pada [0; 2π].
  • 6.7 Dengan substitusi: (a) ∫ 2x/(x² + 1) dx; (b) ∫₀¹ x e^(x²) dx; (c) ∫ cos x · sin³x dx.
  • 6.8 Dengan integrasi parsial: (a) ∫ x e^(−x) dx; (b) ∫₀^π x sin x dx; (c) ∫₁^e x ln x dx.
  • 6.9 Kerucut dibuat dengan memutar f(x) = x/2 pada [0; 6] mengelilingi sumbu x. Hitung volumenya, lalu cocokkan dengan rumus kerucut (1/3)πr²h.
  • 6.10 Hitung (a) ∫₁^∞ 1/x³ dx dan (b) ∫₀^∞ e^(−2x) dx.
  • 6.11 Kecepatan suatu benda v(t) = 6t − t² (m/s) untuk 0 ≤ t ≤ 6. Hitung jarak yang ditempuh dan kecepatan rata-ratanya. Beri Antwortsatz.
