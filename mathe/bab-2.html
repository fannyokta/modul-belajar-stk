Kalkulus di Bab 4 sampai 6 hanyalah alat untuk menganalisis fungsi, jadi kemampuan membaca dan membuat sketsa fungsi menentukan hampir semuanya. Bab ini mencakup sifat dasar fungsi, polinom, fungsi rasional, eksponen dan logaritma, serta komposisi dan invers.

2.1 Sifat dasar fungsi

  • Definitionsmenge 𝔻: semua x yang boleh dimasukkan. Waspadai penyebut nol, akar dari bilangan negatif, dan logaritma dari bilangan tak positif.
  • Wertemenge 𝕎: semua nilai y yang mungkin dihasilkan.
  • Nullstellen: nilai x dengan f(x) = 0 (titik potong sumbu x).
  • Symmetrie: jika f(−x) = f(x), grafik simetris terhadap sumbu y (achsensymmetrisch, fungsi genap). Jika f(−x) = −f(x), grafik simetris terhadap titik asal (punktsymmetrisch, fungsi ganjil).

2.2 Polinom (Ganzrationale Funktionen)

Bentuk umum f(x) = aₙxⁿ + … + a₁x + a₀ dengan aₙ ≠ 0; n disebut Grad (derajat). Perilaku untuk x → ±∞ (Verhalten im Unendlichen) ditentukan oleh suku berpangkat tertinggi saja:

Derajat aₙ > 0 aₙ < 0
Genap naik di kedua ujung (→ +∞ dan +∞) turun di kedua ujung (→ −∞ dan −∞)
Ganjil x → −∞ memberi −∞, x → +∞ memberi +∞ x → −∞ memberi +∞, x → +∞ memberi −∞

Mencari nol polinom derajat 3 atau lebih:

  1. Tebak satu nol di antara pembagi bilangan konstan (Absolutglied), mis. ±1, ±2, ±3, …
  2. Lakukan Polynomdivision dengan faktor (x − x₀).
  3. Selesaikan sisa persamaan kuadratnya dengan pq-Formel.

Contoh 1. f(x) = x³ − 2x² − 5x + 6.

Coba x = 1: 1 − 2 − 5 + 6 = 0, jadi x = 1 adalah nol. Pembagian: (x³ − 2x² − 5x + 6) : (x − 1) = x² − x − 6. Cek dengan mengalikan balik: (x − 1)(x² − x − 6) = x³ − 2x² − 5x + 6 ✓. Lalu x² − x − 6 = (x − 3)(x + 2), sehingga nolnya x = 1, x = 3, dan x = −2.

Jika faktor (x − x₀) muncul dua kali, x₀ disebut nol ganda (doppelte Nullstelle): grafik menyentuh sumbu x tanpa memotongnya.

2.3 Fungsi rasional (Gebrochenrationale Funktionen)

Bentuk f(x) = Z(x)/N(x) dengan pembilang Z dan penyebut N. Nol penyebut adalah Definitionslücke. Ada dua jenis:

  • Polstelle (asimtot tegak): nol penyebut yang bukan nol pembilang. Grafik meledak ke ±∞.
  • Hebbare Lücke (lubang): nol penyebut yang juga nol pembilang, sehingga faktornya bisa dicoret. Grafik hanya punya “lubang” di titik itu.

Asimtot untuk x → ±∞ (bandingkan derajat pembilang dan penyebut):

Derajat Z dibanding N Asimtot
lebih kecil y = 0 (waagerechte Asymptote)
sama y = (koefisien utama Z) / (koefisien utama N)
lebih besar satu asimtot miring (schräge Asymptote), dicari dengan Polynomdivision

Contoh 2. f(x) = (x² − 1)/(x² − 4).

Penyebut x² − 4 = (x − 2)(x + 2), jadi 𝔻 = ℝ \ {−2; 2}. Pembilang (x − 1)(x + 1) tidak berbagi faktor dengan penyebut, sehingga x = ±2 keduanya Polstelle. Nol: x = ±1. Derajat sama dengan koefisien utama 1 dan 1, jadi asimtot datar y = 1.

Contoh 3. f(x) = (x² + 1)/x = x + 1/x.

Polstelle di x = 0. Untuk |x| besar, 1/x → 0 sehingga grafik mendekati garis miring y = x.

2.4 Eksponen dan logaritma (Exponential- und Logarithmusfunktionen)

Fungsi eksponen f(x) = aˣ (a > 0, a ≠ 1) dan khususnya e-Funktion f(x) = eˣ dengan e ≈ 2,718. Fungsi logaritma adalah inversnya: ln x = logₑ x.

a^x = e^{x \ln a}, \qquad \ln(uv) = \ln u + \ln v, \qquad \ln\frac{u}{v} = \ln u - \ln v, \qquad \ln(u^r) = r \ln u
a^x = b \;\Leftrightarrow\; x = \log_a b = \frac{\ln b}{\ln a}

Sifat penting: eˣ > 0 untuk semua x, dan ln x hanya terdefinisi untuk x > 0.

Contoh 4. 2^(x+1) = 12.

x + 1 = ln 12 / ln 2 ≈ 3,585, jadi x ≈ 2,585. (Setara: x = log₂ 6.)

Contoh 5 (substitusi). e^(2x) − 3e^x + 2 = 0.

Misal z = eˣ (z > 0): z² − 3z + 2 = 0, jadi z = 1 atau z = 2. Maka x = ln 1 = 0 atau x = ln 2.

Contoh 6 (logaritma). ln x + ln(x − 2) = ln 3.

Syarat: x > 2. Gabungkan: ln(x(x − 2)) = ln 3, jadi x² − 2x − 3 = 0 dan x = 3 atau x = −1. Hanya x = 3 yang memenuhi syarat x > 2. Jadi 𝕃 = {3}.

Contoh 7 (peluruhan). Zat radioaktif dengan waktu paruh (Halbwertszeit) 5 tahun. Kapan sisanya 10%?

Modelnya N(t) = N₀ · e^(−kt) dengan e^(−5k) = 1/2, jadi k = ln 2 / 5 ≈ 0,1386. Kita cari 0,1 = e^(−kt), sehingga t = ln 10 / k = 5 · ln 10 / ln 2 ≈ 16,6 tahun. Antwortsatz: setelah sekitar 16,6 tahun, sisanya tinggal 10%.

2.5 Komposisi dan invers

Komposisi (Verkettung): (f ∘ g)(x) = f(g(x)), artinya kerjakan g dulu, baru f. Umumnya f ∘ g ≠ g ∘ f.

Invers (Umkehrfunktion) f⁻¹ ada jika f satu-satu (injektif) pada daerahnya. Cara mencarinya: tulis y = f(x), tukar x dan y, lalu selesaikan untuk y. Grafik f⁻¹ adalah cermin grafik f terhadap garis y = x.

Contoh 8. f(x) = (x + 1)/(x − 2), x ≠ 2.

Tulis y = (x + 1)/(x − 2), jadi y(x − 2) = x + 1 dan yx − 2y = x + 1. Kumpulkan x: x(y − 1) = 2y + 1, sehingga x = (2y + 1)/(y − 1). Tukar nama peubah: f⁻¹(x) = (2x + 1)/(x − 1).

2.6 Transformasi grafik

Bentuk Pengaruh pada grafik f
f(x) + b geser b satuan ke atas (ke bawah jika b < 0)
f(x − a) geser a satuan ke kanan (ke kiri jika a < 0)
c · f(x) regangan faktor c searah sumbu y (jika c < 0, grafik juga dicerminkan terhadap sumbu x)
f(bx) pemampatan faktor 1/b searah sumbu x (jika b < 0, grafik juga dicerminkan terhadap sumbu y)
