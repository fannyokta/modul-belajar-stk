Sebagian besar kesalahan di bab-bab berikutnya bukan berasal dari kalkulus, tetapi dari aljabar yang goyah. Bab ini mengunci lima keterampilan: pangkat, persamaan kuadrat, persamaan pecahan dan akar, nilai mutlak, dan pertidaksamaan.

1.1 Pangkat dan akar (Potenzen und Wurzeln)

a^m \cdot a^n = a^{m+n}, \quad \frac{a^m}{a^n} = a^{m-n}, \quad (a^m)^n = a^{m n}, \quad a^{-n} = \frac{1}{a^n}, \quad a^{m/n} = \sqrt[n]{a^m}

Rumus selisih kuadrat dan kuadrat sempurna (Binomische Formeln) sangat sering dipakai untuk memfaktorkan:

(a+b)^2 = a^2 + 2ab + b^2, \quad (a-b)^2 = a^2 - 2ab + b^2, \quad (a+b)(a-b) = a^2 - b^2

Contoh 1. Sederhanakan (a³b⁻²)² : (a⁻¹b³).

Pangkatkan dulu: (a³b⁻²)² = a⁶b⁻⁴. Lalu bagi: a⁶⁻⁽⁻¹⁾ = a⁷ dan b⁻⁴⁻³ = b⁻⁷. Hasilnya a⁷/b⁷.

1.2 Persamaan kuadrat (Quadratische Gleichungen)

Di Jerman, rumus yang paling sering dipakai adalah pq-Formel. Pastikan bentuknya dulu x² + px + q = 0 (koefisien x² harus 1, jadi bagi dulu jika perlu).

x^2 + px + q = 0 \;\Rightarrow\; x_{1,2} = -\frac{p}{2} \pm \sqrt{\left(\frac{p}{2}\right)^2 - q}

Bagian di bawah akar disebut Diskriminante D = (p/2)² − q. Jika D > 0 ada dua solusi, D = 0 satu solusi, D < 0 tidak ada solusi real. Untuk bentuk umum ax² + bx + c = 0 dipakai abc-Formel:

x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}

Satz von Vieta (jumlah dan hasil kali akar): untuk x² + px + q = 0 berlaku x₁ + x₂ = −p dan x₁ · x₂ = q.

Satz vom Nullprodukt: hasil kali bernilai nol jika salah satu faktornya nol. Ini kunci menyelesaikan persamaan yang sudah terfaktor.

Contoh 2. 2x² − 8x − 10 = 0.

Bagi 2: x² − 4x − 5 = 0, jadi p = −4 dan q = −5. Maka x = 2 ± √(4 + 5) = 2 ± 3, yaitu x = 5 atau x = −1. Cek: 2·25 − 40 − 10 = 0 ✓.

Contoh 3 (substitusi, bikuadrat). x⁴ − 5x² + 4 = 0.

Misal z = x². Maka z² − 5z + 4 = 0, jadi z = 4 atau z = 1. Kembalikan: x² = 4 memberi x = ±2, dan x² = 1 memberi x = ±1. Himpunan penyelesaian (Lösungsmenge): 𝕃 = {−2, −1, 1, 2}.

1.3 Persamaan pecahan (Bruchgleichungen)

Langkah wajib: tentukan dulu Definitionsmenge 𝔻, yaitu nilai x yang membuat penyebut nol dan harus dikeluarkan. Setelah itu kalikan kedua ruas dengan penyebut persekutuan. Di akhir, buang solusi yang tidak masuk 𝔻.

Contoh 4. 2/(x−1) + 3/(x+1) = 5/(x²−1).

Penyebut: x − 1 ≠ 0 dan x + 1 ≠ 0, jadi 𝔻 = ℝ \ {−1; 1}. Kalikan dengan (x−1)(x+1): 2(x+1) + 3(x−1) = 5, sehingga 5x − 1 = 5 dan x = 6/5. Nilai ini ada di 𝔻, jadi 𝕃 = {6/5}.

1.4 Persamaan akar (Wurzelgleichungen)

Isolasi akarnya, kuadratkan kedua ruas, selesaikan, lalu wajib diperiksa (Probe) karena mengkuadratkan bisa memunculkan solusi palsu.

Contoh 5. √(x+3) = x − 3.

Kuadratkan: x + 3 = x² − 6x + 9, jadi x² − 7x + 6 = 0, sehingga x = 6 atau x = 1. Probe untuk x = 6: √9 = 3 dan 6 − 3 = 3 ✓. Probe untuk x = 1: √4 = 2 tetapi 1 − 3 = −2 ✗. Jadi 𝕃 = {6}.

1.5 Nilai mutlak (Betrag)

|x| = \begin{cases} x & \text{jika } x \ge 0 \\ -x & \text{jika } x < 0 \end{cases}

Untuk |u| = c dengan c > 0: u = c atau u = −c. Jika ada x di kedua sisi, gunakan Fallunterscheidung (pisahkan kasus) dan periksa tiap kasus terhadap syaratnya.

Contoh 6. |x − 1| = 2x + 1.

Kasus x ≥ 1: x − 1 = 2x + 1, jadi x = −2, tetapi tidak memenuhi x ≥ 1. Kasus x < 1: −(x − 1) = 2x + 1, jadi −x + 1 = 2x + 1 dan x = 0, yang memenuhi x < 1 ✓. Probe: |0 − 1| = 1 = 2·0 + 1 ✓. Jadi 𝕃 = {0}.

1.6 Pertidaksamaan (Ungleichungen)

Aturan emas: kalikan atau bagi dengan bilangan negatif membalik tanda. Untuk pertidaksamaan kuadrat dan pecahan, cari titik nol lalu periksa tanda di tiap interval.

Contoh 7. x² − x − 6 < 0.

Faktorkan: (x − 3)(x + 2) < 0. Parabola terbuka ke atas, jadi nilainya negatif di antara kedua akar: 𝕃 = (−2; 3), kadang ditulis ]−2; 3[.

Contoh 8 (pecahan). (x+1)/(x−2) ≥ 0.

Pembilang nol di x = −1 dan penyebut nol di x = 2. Tanda pecahan positif untuk x < −1, negatif untuk −1 < x < 2, dan positif untuk x > 2. Karena ≥ 0, x = −1 ikut (pembilang nol) tetapi x = 2 tidak (penyebut nol). Jadi 𝕃 = (−∞; −1] ∪ (2; ∞). Jangan mengalikan dengan (x − 2) tanpa memisahkan kasus tandanya.

Kesalahan yang paling sering terjadi

  • Menjumlahkan pecahan dengan menjumlahkan penyebutnya.
  • Lupa Probe pada persamaan akar dan persamaan nilai mutlak.
  • Lupa membalik tanda saat mengalikan dengan bilangan negatif.
  • Memakai pq-Formel padahal koefisien x² belum 1.
  • Mencoret suku, bukan faktor: (x² + 3x)/x bukan x + 3x, tetapi x + 3.
