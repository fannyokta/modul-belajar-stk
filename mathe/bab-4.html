Bab 4

Limit dan Kekontinuan

Grenzwerte und Stetigkeit

Di bab ini

  • 4.2 Teknik menghitung limit
  • 4.3 Kekontinuan (Stetigkeit)
  • Latihan 4

Limit adalah jembatan menuju turunan dan integral. Kamu tidak perlu bukti formal ε-δ; yang dibutuhkan adalah keterampilan menghitung limit dan memahami artinya secara grafis.

4.1 Gagasan limit

\lim_{x \to x_0} f(x) = L

Artinya: nilai f(x) mendekati L ketika x mendekati x₀, tanpa harus sama dengan x₀. Limit sepihak ditulis lim dari kiri (linksseitiger Grenzwert) dan lim dari kanan (rechtsseitiger Grenzwert). Limit ada jika keduanya ada dan sama.

Untuk x → ±∞, limit menggambarkan asimtot datar. Jika f(x) membesar tak terbatas dekat suatu titik, limitnya ±∞ (asimtot tegak).

4.2 Teknik menghitung limit

  1. Substitusi langsung. Jika hasilnya angka biasa, selesai.
  2. Bentuk 0/0: faktorkan lalu coret, atau kalikan sekawan (konjugat) jika ada akar.
  3. x → ∞ pada pecahan: bagi pembilang dan penyebut dengan pangkat x tertinggi.
  4. Limit istimewa yang perlu dihafal:
\lim_{x \to 0} \frac{\sin x}{x} = 1, \qquad \lim_{x \to \infty} \left(1 + \frac{k}{x}\right)^x = e^k, \qquad \lim_{x \to \infty} x^n e^{-x} = 0, \qquad \lim_{x \to \infty} \frac{\ln x}{x} = 0

Contoh 1 (faktorisasi). lim (x² − 4)/(x − 2) untuk x → 2.

Substitusi memberi 0/0. Faktorkan: (x − 2)(x + 2)/(x − 2) = x + 2, jadi limitnya 4.

Contoh 2 (konjugat). lim (√(x+4) − 2)/x untuk x → 0.

Kalikan dengan (√(x+4) + 2)/(√(x+4) + 2): pembilang menjadi (x + 4) − 4 = x. Maka ungkapannya x/(x(√(x+4) + 2)) = 1/(√(x+4) + 2), dan limitnya 1/4.

Contoh 3 (tak hingga). lim (3x² + x)/(2x² − 5) untuk x → ∞.

Bagi dengan x²: (3 + 1/x)/(2 − 5/x²) → 3/2.

Contoh 4 (sinus). lim sin(3x)/x untuk x → 0.

Tulis sin(3x)/x = 3 · sin(3x)/(3x). Karena sin(u)/u → 1 untuk u → 0, limitnya 3.

Contoh 5 (sepihak). f(x) = 1/(x − 1) di x = 1.

Dari kanan (x > 1) nilainya +∞, dari kiri (x < 1) nilainya −∞. Limitnya tidak ada, dan x = 1 adalah Polstelle.

4.3 Kekontinuan (Stetigkeit)

Fungsi f kontinu di x₀ jika tiga hal terpenuhi: f(x₀) ada, limit di x₀ ada, dan keduanya sama.

\lim_{x \to x_0^-} f(x) = \lim_{x \to x_0^+} f(x) = f(x_0)

Secara gambar: grafik bisa digambar tanpa mengangkat pensil. Polinom, eksponen, sinus, dan kosinus kontinu di mana-mana; fungsi rasional kontinu di seluruh 𝔻.

Contoh 6 (mencari parameter). f(x) = x² + a untuk x < 1, dan f(x) = 3x − 1 untuk x ≥ 1. Tentukan a agar f kontinu di x = 1.

Limit kiri: 1 + a. Nilai f(1) = 3 − 1 = 2. Samakan keduanya: 1 + a = 2, jadi a = 1.

Zwischenwertsatz (teorema nilai antara): jika f kontinu pada [a; b] dan f(a), f(b) berbeda tanda, maka ada setidaknya satu nol di antara a dan b.

Contoh 7. Tunjukkan x³ + x − 1 = 0 punya solusi di (0; 1).

f(0) = −1 < 0 dan f(1) = 1 > 0, dan f kontinu. Jadi menurut teorema nilai antara ada nol di (0; 1).
