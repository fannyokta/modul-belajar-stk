Kunci Jawaban dan Pembahasan

Buka bagian ini setelah kamu mengerjakan soalnya sendiri. Jika jawabanmu berbeda, cari langkah pertama yang berbeda dulu, jangan langsung menyalin hasil akhirnya.

Kunci Latihan 1 (Aljabar)

  • 1.1 (2x³y⁻¹)³ = 8x⁹y⁻³. Dibagi 4x⁻²y² menjadi 2x¹¹y⁻⁵ = 2x¹¹/y⁵.
  • 1.2 27^(2/3) = (∛27)² = 9 dan 16^(−1/4) = 1/⁴√16 = 1/2. Jumlahnya 9,5 = 19/2.
  • 1.3 Bagi 3: x² − 4x + 3 = 0, jadi x = 2 ± √(4 − 3) = 2 ± 1. 𝕃 = {1; 3}.
  • 1.4 D = (p/2)² − q = 9 − 10 = −1 < 0. 𝕃 = {} (tidak ada solusi real).
  • 1.5 Misal z = x²: z² − 13z + 36 = 0, jadi z = (13 ± 5)/2 = 9 atau 4. Maka x = ±3 atau ±2. 𝕃 = {−3; −2; 2; 3}.
  • 1.6 𝔻 = ℝ \ {−2; 2}. Kalikan (x + 2)(x − 2): x(x − 2) + (x + 2) = 8, jadi x² − x − 6 = 0 dan x = 3 atau x = −2. Nilai x = −2 tidak ada di 𝔻. 𝕃 = {3}. Cek: 3/5 + 1 = 8/5 ✓.
  • 1.7 Kuadratkan: 2x + 1 = x² − 2x + 1, jadi x² − 4x = 0 dan x = 0 atau x = 4. Probe x = 0: √1 = 1 tetapi 0 − 1 = −1 ✗. Probe x = 4: √9 = 3 = 4 − 1 ✓. 𝕃 = {4}.
  • 1.8 3x − 6 = 9 memberi x = 5, dan 3x − 6 = −9 memberi x = −1. 𝕃 = {−1; 5}.
  • 1.9 Kasus x ≥ −2: x + 2 = 3x − 2, jadi x = 2 (memenuhi). Kasus x < −2: −x − 2 = 3x − 2, jadi x = 0 (tidak memenuhi x < −2). Probe: |4| = 4 = 3·2 − 2 ✓. 𝕃 = {2}.
  • 1.10 (x − 5)(x + 1) ≥ 0, jadi x ≤ −1 atau x ≥ 5. 𝕃 = (−∞; −1] ∪ [5; ∞).
  • 1.11 (2x − 1)/(x + 3) − 1 < 0 menjadi (x − 4)/(x + 3) < 0, jadi −3 < x < 4. 𝕃 = (−3; 4).
  • 1.12 −3 < x − 2 < 3, jadi −1 < x < 5.
  • 1.13 x(x² − 3x − 4) = x(x − 4)(x + 1) = 0. 𝕃 = {−1; 0; 4}.
  • 1.14 a + b = 10 dan ab = 21, jadi a dan b adalah akar t² − 10t + 21 = 0, yaitu t = 5 ± 2. Antwortsatz: sisi-sisinya 3 m dan 7 m.

Kunci Latihan 2 (Fungsi)

  • 2.1 Syarat: x − 1 ≥ 0 dan x ≠ 4. 𝔻 = [1; ∞) \ {4}. Nol: pembilang 0 memberi x = 1, yang ada di 𝔻.
  • 2.2 f(−x) = f(x), jadi f achsensymmetrisch. g(−x) = −x³ + x = −g(x), jadi g punktsymmetrisch. h(−x) = x² − x tidak sama dengan h(x) maupun −h(x), jadi h tidak simetris.
  • 2.3 (x³ − 6x² + 11x − 6) : (x − 1) = x² − 5x + 6 = (x − 2)(x − 3). Nol: 1, 2, 3.
  • 2.4 x = −1 adalah nol (−1 + 2 + 5 − 6 = 0). (x³ + 2x² − 5x − 6) : (x + 1) = x² + x − 6 = (x + 3)(x − 2). Nol: −3, −1, 2.
  • 2.5 Suku dominan −2x⁵: untuk x → +∞, f → −∞, dan untuk x → −∞, f → +∞.
  • 2.6 Penyebut (x − 2)(x + 1), jadi 𝔻 = ℝ \ {−1; 2}. Pembilang 2(x − 1)(x + 1). Untuk x ≠ −1, f(x) = 2(x − 1)/(x − 2). Nol: x = 1. Polstelle: x = 2. Hebbare Lücke di x = −1 dengan nilai 2(−2)/(−3) = 4/3, jadi lubang di (−1|4/3). Asimtot datar: y = 2.
  • 2.7 Misal z = 3ˣ: z² − 4z + 3 = 0, jadi z = 1 atau 3, sehingga x = 0 atau 1. 𝕃 = {0; 1}.
  • 2.8 Syarat x > 1. ln((x + 1)(x − 1)) = ln 8 memberi x² − 1 = 8, jadi x = ±3, dan hanya x = 3 memenuhi. 𝕃 = {3}.
  • 2.9 500 · 1,15ᵗ = 2000 memberi 1,15ᵗ = 4, jadi t = ln 4/ln 1,15 ≈ 9,92. Antwortsatz: setelah sekitar 9,9 jam, populasi mencapai 2000.
  • 2.10 y = 3x − 6 menjadi x = (y + 6)/3. f⁻¹(x) = (x + 6)/3 = x/3 + 2.
  • 2.11 y = e^(2x) + 1 memberi e^(2x) = y − 1, jadi x = ½ ln(y − 1). f⁻¹(x) = ½ ln(x − 1) dengan daerah definisi (1; ∞).
  • 2.12 (f ∘ g)(x) = (x + 3)² = x² + 6x + 9 dan (g ∘ f)(x) = x² + 3. Keduanya berbeda.
  • 2.13 Dari y = x²: geser 1 satuan ke kanan, regangan faktor 2 searah sumbu y, cermin terhadap sumbu x, lalu geser 3 satuan ke atas. Titik puncak (1|3), terbuka ke bawah.
  • 2.14 N = 80 · (1/2)^(20/8) = 80 · 2^(−2,5) = 80/(4√2) = 10√2 ≈ 14,1 mg.

Kunci Latihan 3 (Trigonometri)

  • 3.1 150° = 150 · π/180 = 5π/6. 7π/4 rad = 7 · 180°/4 = 315°.
  • 3.2 sin 120° = sin 60° = √3/2. cos(5π/6) = −cos(π/6) = −√3/2. tan 225° = tan 45° = 1.
  • 3.3 cos²α = 1 − 9/25 = 16/25. Di kuadran II, cos α = −4/5, dan tan α = (3/5)/(−4/5) = −3/4.
  • 3.4 (sin x + cos x)² = 1 + 2 sin x cos x. Dikurangi 2 sin x cos x tersisa 1.
  • 3.5 sin 2x = 2 sin x cos x dan 1 + cos 2x = 2cos²x. Hasil bagi = sin x/cos x = tan x (untuk cos x ≠ 0).
  • 3.6 f(x) = 2 sin(3(x − π/6)) − 1. Amplitudo 2, periode 2π/3, geser π/6 ke kanan, garis tengah y = −1, dan 𝕎 = [−3; 1].
  • 3.7 sin x = √3/2, jadi x = π/3 atau 2π/3.
  • 3.8 Misal z = cos x: 2z² + z − 1 = 0, jadi z = 1/2 atau z = −1. cos x = 1/2 memberi x = π/3 dan 5π/3. cos x = −1 memberi x = π. 𝕃 = {π/3; π; 5π/3}.
  • 3.9 cos 2x = 2cos²x − 1, jadi 2cos²x − cos x − 1 = 0 dengan cos x = 1 atau −1/2. 𝕃 = {0; 2π/3; 4π/3}.
  • 3.10 tan x = −1, jadi x = 3π/4 atau 7π/4.
  • 3.11 c² = 25 + 64 − 80 cos 50° ≈ 89 − 51,42 = 37,58, jadi c ≈ 6,13.
  • 3.12 Sudut terbesar di depan sisi 9: cos γ = (36 + 49 − 81)/(2·6·7) = 4/84 = 1/21, jadi γ ≈ 87,3°.
  • 3.13 tan 35° = h/40, jadi h = 40 · tan 35° ≈ 28,0 m. Antwortsatz: menara setinggi sekitar 28,0 m (dihitung dari tinggi mata pengamat; tambahkan tinggi mata jika diminta tinggi total).

Kunci Latihan 4 (Limit)

  • 4.1 (x − 3)(x + 3)/(x − 3) = x + 3, jadi limit 6.
  • 4.2 (x − 1)(x − 2)/((x − 1)(x + 1)) = (x − 2)/(x + 1), jadi limit −1/2.
  • 4.3 Kalikan konjugat: ((x + 9) − 9)/(x(√(x+9) + 3)) = 1/(√(x+9) + 3), jadi limit 1/6.
  • 4.4 Bagi x³: (4 − 1/x²)/(2 + 7/x) → 4/2 = 2.
  • 4.5 Bagi x²: (5/x + 1/x²)/(1 + 3/x²) → 0.
  • 4.6 sin(5x)/(2x) = (5/2) · sin(5x)/(5x) → 5/2.
  • 4.7 (1 + 2/x)ˣ → e².
  • 4.8 Dari kanan x + 2 kecil dan positif, jadi nilainya +∞. Dari kiri x + 2 kecil dan negatif, jadi −∞. Limit tidak ada, dan x = −2 adalah Polstelle.
  • 4.9 Limit kiri 4 − 2a dan f(2) = 3. Samakan keduanya: 4 − 2a = 3, jadi a = 1/2.
  • 4.10 Untuk g(x) = cos x − x: g(0) = 1 > 0 dan g(1) = cos 1 − 1 ≈ −0,46 < 0. Karena g kontinu, menurut Zwischenwertsatz ada nol di (0; 1).
  • 4.11 √(x² + x) − x = x/(√(x² + x) + x) = 1/(√(1 + 1/x) + 1) → 1/2.

Kunci Latihan 5 (Turunan)

  • 5.1 ((x + h)² + 3(x + h) − x² − 3x)/h = (2xh + h² + 3h)/h = 2x + h + 3, jadi f′(x) = 2x + 3.
  • 5.2 (a) 12x² − 10x + 7. (b) 3√x = 3x^(1/2) menjadi 3/(2√x), dan 2/x menjadi −2/x², jadi 3/(2√x) − 2/x². (c) e^(−x) − x e^(−x) = (1 − x)e^(−x). (d) (2x(x + 1) − x²)/(x + 1)² = (x² + 2x)/(x + 1)². (e) (2x + 4)/(x² + 4x). (f) 2 sin x cos x = sin 2x. (g) 2x · e^(x²−1). (h) −3 sin(3x + 1).
  • 5.3 f(3) = 2 dan f′(x) = 2x − 4, jadi f′(3) = 2. Tangente: y = 2(x − 3) + 2 = 2x − 4. Normale: y = −½(x − 3) + 2 = −x/2 + 7/2.
  • 5.4 f′(x) = 2x − 6 = 2 memberi x = 4, dan f(4) = 16 − 24 + 10 = 2. Titiknya (4|2).
  • 5.5 f(x) = x³ − 3x. Punktsymmetrisch karena f(−x) = −f(x). Nol: x(x² − 3) = 0, jadi x = 0 dan x = ±√3. f′ = 3x² − 3 = 0 memberi x = ±1, dan f″ = 6x. f″(1) = 6 > 0, jadi T(1|−2). f″(−1) = −6 < 0, jadi H(−1|2). f″ = 0 di x = 0 dengan f‴ = 6 ≠ 0, jadi W(0|0). Perilaku: x → +∞ memberi +∞, x → −∞ memberi −∞.
  • 5.6 f(x) = x⁴ − 2x², achsensymmetrisch. Nol: x²(x² − 2) = 0, jadi x = 0 (ganda) dan x = ±√2. f′ = 4x(x² − 1), jadi x = 0, ±1. f″ = 12x² − 4. f″(0) = −4, jadi H(0|0). f″(±1) = 8, jadi T(−1|−1) dan T(1|−1). f″ = 0 memberi x = ±√3/3 dengan f‴ = 24x ≠ 0, dan f(±√3/3) = 1/9 − 2/3 = −5/9. W(±√3/3 | −5/9). Untuk x → ±∞, f → +∞.
  • 5.7 Dua sisi tegak a dan satu sisi sejajar dinding b: 2a + b = 60, jadi b = 60 − 2a. A(a) = a(60 − 2a) = 60a − 2a² untuk 0 < a < 30. A′ = 60 − 4a = 0 memberi a = 15, dan A″ = −4 < 0. Maka b = 30 dan A = 450. Antwortsatz: ukuran 15 m × 30 m (sisi 30 m sejajar dinding) memberi luas maksimum 450 m².
  • 5.8 h = 500/(πr²) dan O(r) = 2πr² + 2πrh = 2πr² + 1000/r. O′ = 4πr − 1000/r² = 0 memberi r³ = 250/π, jadi r ≈ 4,30 cm. O″ = 4π + 2000/r³ > 0, jadi minimum. Maka h ≈ 8,60 cm (= 2r). Antwortsatz: r ≈ 4,30 cm dan h ≈ 8,60 cm.
  • 5.9 f′ = 3x². x₁ = 1,5 − (3,375 − 2)/(3·2,25) = 1,5 − 1,375/6,75 ≈ 1,2963. x₂ = 1,2963 − (1,2963³ − 2)/(3·1,2963²) ≈ 1,2963 − 0,1783/5,0412 ≈ 1,2609. (Nilai sebenarnya ∛2 ≈ 1,2599.)
  • 5.10 (a) lim 2e^(2x)/1 = 2. (b) lim sin x/(2x) = 1/2. (c) lim 2x/eˣ = lim 2/eˣ = 0.

Kunci Latihan 6 (Integral)

  • 6.7 (a) u = x² + 1: ln(x² + 1) + C. (b) u = x²: ½∫₀¹ e^u du = ½(e − 1) ≈ 0,859. (c) u = sin x: ∫ u³ du = sin⁴x/4 + C.

  • (a) (x − 3)²(x + 3) = (x² − 6x + 9)(x + 3) = x³ − 3x² − 9x + 27 ✓. Nol: x = 3 (ganda) dan x = −3. (3 P)
