Di Jerman, sudut di kalkulus selalu dalam radian (Bogenmaß), bukan derajat. Bab ini membangun kebiasaan itu, lalu membahas identitas, grafik, persamaan, dan penerapan pada segitiga.

3.1 Radian dan lingkaran satuan

180^\circ = \pi \text{ rad}, \qquad \alpha_{\text{rad}} = \alpha^\circ \cdot \frac{\pi}{180^\circ}

Pada lingkaran satuan (jari-jari 1), titik untuk sudut x memiliki koordinat (cos x; sin x). Maka tan x = sin x / cos x, dan tan x tidak terdefinisi saat cos x = 0.

Nilai istimewa yang harus hafal:

Sudut (derajat) 0° 30° 45° 60° 90°
Sudut (radian) 0 π/6 π/4 π/3 π/2
sin 0 1/2 √2/2 √3/2 1
cos 1 √3/2 √2/2 1/2 0
tan 0 √3/3 1 √3 tak terdefinisi

Untuk sudut di kuadran lain, ubah ke sudut acuan lalu tentukan tandanya: sin positif di kuadran I dan II, cos positif di kuadran I dan IV, tan positif di kuadran I dan III.

3.2 Identitas penting

\sin^2 x + \cos^2 x = 1
\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta, \qquad \cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta
\sin 2x = 2\sin x\cos x, \qquad \cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x

Sifat simetri dan periode: sin(−x) = −sin x, cos(−x) = cos x, sin(π − x) = sin x, cos(π − x) = −cos x. Sinus dan kosinus berperiode 2π, tangen berperiode π.

3.3 Grafik sinus dan kosinus

Bentuk umum: f(x) = a · sin(b(x − c)) + d.

  • Amplitude: |a| (tinggi gelombang dari garis tengah).
  • Periode: 2π/|b| (panjang satu gelombang penuh).
  • Phasenverschiebung: c (geser ke kanan jika c > 0).
  • Mittellinie: y = d (garis tengah), sehingga Wertemenge-nya [d − |a|; d + |a|].

Contoh 1. f(x) = 3 sin(2x − π) + 1.

Faktorkan b: 3 sin(2(x − π/2)) + 1. Jadi amplitudo 3, periode 2π/2 = π, geser π/2 ke kanan, garis tengah y = 1. Wertemenge: [−2; 4].

3.4 Persamaan trigonometri

Selesaikan dulu di satu periode, lalu tambahkan kelipatan periode jika daerahnya tak dibatasi.

\sin x = c: \; x = \arcsin c + 2k\pi \text{ atau } x = \pi - \arcsin c + 2k\pi
\cos x = c: \; x = \pm \arccos c + 2k\pi, \qquad \tan x = c: \; x = \arctan c + k\pi \qquad (k \in \mathbb{Z})

Contoh 2. sin x = 1/2 pada [0; 2π).

arcsin(1/2) = π/6. Solusi kedua: π − π/6 = 5π/6. Jadi 𝕃 = {π/6; 5π/6}.

Contoh 3 (substitusi). 2cos²x − cos x − 1 = 0 pada [0; 2π).

Misal z = cos x: 2z² − z − 1 = 0, jadi z = (1 ± 3)/4, yaitu z = 1 atau z = −1/2. cos x = 1 memberi x = 0. cos x = −1/2 memberi x = 2π/3 dan x = 4π/3. Jadi 𝕃 = {0; 2π/3; 4π/3}.

Contoh 4 (sudut ganda). sin 2x = sin x pada [0; 2π).

2 sin x cos x − sin x = 0, sehingga sin x (2 cos x − 1) = 0. Dari sin x = 0 diperoleh x = 0 dan x = π. Dari cos x = 1/2 diperoleh x = π/3 dan x = 5π/3. Jadi 𝕃 = {0; π/3; π; 5π/3}. Jangan membagi dengan sin x, karena itu menghilangkan solusi.

3.5 Segitiga sembarang

\text{Sinussatz: } \frac{a}{\sin\alpha} = \frac{b}{\sin\beta} = \frac{c}{\sin\gamma}, \qquad \text{Kosinussatz: } c^2 = a^2 + b^2 - 2ab\cos\gamma

Contoh 5. a = 7, b = 9, γ = 60°. Cari c.

c² = 49 + 81 − 2·7·9·cos 60° = 130 − 63 = 67, jadi c = √67 ≈ 8,19.

Contoh 6. α = 40°, β = 65°, a = 10. Cari b.

b = a · sin β / sin α = 10 · sin 65° / sin 40° ≈ 14,10.

Perhatian kalkulator: sebelum menghitung, periksa mode DEG atau RAD. Kesalahan mode adalah penyebab nilai salah yang paling sering.
