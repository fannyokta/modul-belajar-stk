Lembar Rumus

Lembar rumus ringkas

Susun lembar rumusmu sendiri dengan menyalin dan merapikan bagian ini, karena menulis ulang membantu mengingat. Periksa dulu apakah Kolleg-mu menyediakan atau mengizinkan Formelsammlung.

Aljabar, eksponen, logaritma

\begin{aligned} &(a \pm b)^2 = a^2 \pm 2ab + b^2, \quad (a+b)(a-b) = a^2 - b^2 \\ &x^2 + px + q = 0 \Rightarrow x = -\tfrac{p}{2} \pm \sqrt{\left(\tfrac{p}{2}\right)^2 - q}, \quad ax^2 + bx + c = 0 \Rightarrow x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \\ &a^x = b \Leftrightarrow x = \frac{\ln b}{\ln a}, \quad \ln(uv) = \ln u + \ln v, \quad \ln(u^r) = r \ln u \end{aligned}

Trigonometri

\begin{aligned} &\sin^2 x + \cos^2 x = 1, \quad \sin 2x = 2\sin x\cos x, \quad \cos 2x = \cos^2 x - \sin^2 x \\ &\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta, \quad \cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta \\ &c^2 = a^2 + b^2 - 2ab\cos\gamma, \quad \frac{a}{\sin\alpha} = \frac{b}{\sin\beta} = \frac{c}{\sin\gamma} \end{aligned}

Turunan dan integral

\begin{aligned} &(x^n)' = n x^{n-1}, \quad (e^x)' = e^x, \quad (\ln x)' = \tfrac{1}{x}, \quad (\sin x)' = \cos x, \quad (\cos x)' = -\sin x \\ &(uv)' = u'v + uv', \quad \left(\tfrac{u}{v}\right)' = \frac{u'v - uv'}{v^2}, \quad (f(g(x)))' = f'(g(x))\,g'(x) \\ &\int x^n\,dx = \tfrac{x^{n+1}}{n+1} + C, \quad \int \tfrac{1}{x}\,dx = \ln|x| + C, \quad \int e^{ax}\,dx = \tfrac{e^{ax}}{a} + C \\ &\int_a^b f\,dx = F(b) - F(a), \quad \int u v'\,dx = uv - \int u' v\,dx, \quad V = \pi\int_a^b f(x)^2\,dx \end{aligned}

Barisan dan deret

\begin{aligned} &a_n = a_1 + (n-1)d, \quad S_n = \tfrac{n}{2}(a_1 + a_n), \qquad a_n = a_1 q^{n-1}, \quad S_n = a_1\tfrac{1-q^n}{1-q}, \quad S_\infty = \tfrac{a_1}{1-q}\ (|q|<1) \\ &\sum_{k=1}^n k = \tfrac{n(n+1)}{2}, \quad \sum_{k=1}^n k^2 = \tfrac{n(n+1)(2n+1)}{6}, \quad K_n = K_0(1+p)^n \end{aligned}

Vektor dan bidang

\begin{aligned} &|\vec a| = \sqrt{a_1^2 + a_2^2 + a_3^2}, \quad \vec a\cdot\vec b = |\vec a||\vec b|\cos\varphi, \quad A_{\triangle} = \tfrac{1}{2}|\vec a\times\vec b|, \quad V_{\text{Spat}} = |(\vec a\times\vec b)\cdot\vec c| \\ &d(Q,E) = \frac{|n_1 q_1 + n_2 q_2 + n_3 q_3 - d|}{|\vec n|}, \quad d(P,g) = \frac{|(\vec P - \vec Q)\times\vec u|}{|\vec u|} \end{aligned}

Bilangan kompleks

\begin{aligned} &z = a + bi = r\,e^{i\varphi}, \quad r = \sqrt{a^2+b^2}, \quad z\bar z = |z|^2, \quad z^n = r^n e^{in\varphi} \\ &z_k = \sqrt[n]{r}\,e^{i(\varphi + 2\pi k)/n}, \quad k = 0,\dots,n-1 \end{aligned}

Statistika dan peluang

\begin{aligned} &\binom{n}{k} = \tfrac{n!}{k!(n-k)!}, \quad P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}, \quad E(X) = np, \quad \sigma = \sqrt{np(1-p)} \\ &P(A\mid B) = \tfrac{P(A\cap B)}{P(B)}, \quad Z = \tfrac{X-\mu}{\sigma} \end{aligned}
